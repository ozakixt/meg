巡り帖 — 店舗とポケふた（Webアプリ）

スターバックス店舗の「巡り帖」に、全国のポケモンマンホール「ポケふた」を加えた版です。
・画面上部の［両方／店舗／ポケふた］で、地図とリストに出す種類を切り替えます。
・地図の緑の点＝店舗（訪問済みは黄緑）、赤い点＝ポケふた（見つけたものは金色）。
・ポケふたを開くと、マンホールの絵柄・描かれたポケモン・設置場所・公式サイトへのリンク・現在地からの経路が出ます。
  絵柄の画像は公式サイトのものをその場で表示しています（アプリには同梱していません）。表示できない環境では「公式サイトで絵柄を見る」ボタンになります。
・スタンプは店舗とポケふたで別々に数えます。「巡り帖」タブでは店舗／ポケふた／都道府県の3つの進み具合を表示します。
・「営業中」で絞り込んでも、ポケふたは常に表示されます（施設内にあって見られる時間が限られるものは、詳細画面の「メモ」に注意書きがあります）。

■ 公開のしかた（いちばん簡単：Netlify Drop）
1. https://app.netlify.com/drop を開く
2. この deploy フォルダ（index.html がある階層）をそのままドラッグ＆ドロップ
3. 発行された https://〜.netlify.app をスマートフォンで開く
4. iPhone：共有ボタン →「ホーム画面に追加」／ Android：メニュー →「ホーム画面に追加」

他に GitHub Pages / Cloudflare Pages でもそのまま動きます（静的ファイルのみ）。

■ 注意
・index.html をダブルクリックで開く（file://）と、路線図や位置情報が動きません。必ず https で公開して使ってください。
・手元のPCで試す場合：このフォルダで「python3 -m http.server」を実行し http://localhost:8000 を開く。
・店舗データは data/stores.csv を最優先で読み込みます。更新するときはこのファイルを差し替えてアップロードし、アプリの「↻ 最新を取得」を押してください（列：store_number,name,address,lat,lon,url）。
  stores.csv が無い／読めない場合は OpenStreetMap から取得します。
・スタンプは各端末のブラウザ内に保存されます（端末間の同期はありません）。
・地図画像は OpenStreetMap 公式タイルを使用しています。少人数の利用を想定しています。多人数に公開する場合は MapTiler / Stadia Maps 等の地図配信サービスへの切り替えを推奨します。
・出典表示（© OpenStreetMap contributors／国土数値情報 鉄道データ）は消さないでください。
・本アプリは非公式です。企業名・ロゴをアプリ名やアイコンに使わないでください。

■ 重ね合わせレイヤー（上部「レイヤー」ボタン）
・HELLO CYCLING／ドコモ・バイクシェア：公共交通オープンデータセンター（ODPT）の公開GBFSからポート位置と空き台数をリアルタイム取得（60秒ごと更新）。
・タイムズカーシェア／dカーシェア：公開データがないため OpenStreetMap の登録分のみ（少なめ）。
  正確なデータがある場合は data/times.csv・data/dcar.csv（列：name,lat,lng,address,url）を置くと優先して使います。

■ 端末間でスタンプを同期する（任意）
静的ファイルだけのサーバーでも使えるよう、無料の Firebase Realtime Database を保存先に使います。
1. https://console.firebase.google.com/ でプロジェクトを作成（Googleアカウントが必要／無料の Spark プランで十分）
2. 「構築 → Realtime Database → データベースを作成」。ロケーションは asia-southeast1（シンガポール）を推奨、「ロックモード」で開始
3. 「ルール」タブに次を貼り付けて公開：
   {"rules":{".read":false,".write":false,"books":{"$id":{".read":"$id.length===64",".write":"$id.length===64","visits":{"$sid":{".validate":"newData.hasChild('t')"}}}}}}
4. 「プロジェクトの設定 → マイアプリ → ウェブアプリを追加」で表示される firebaseConfig の値を sync-config.js に貼り付け（databaseURL も必ず含める）
5. アップロード後、各端末で「巡り帖」タブ →「端末間で同期」に同じ合言葉を入力
・合言葉は端末内に保存され、サーバーにはそのハッシュ値だけが送られます。合言葉を知っている人は記録を読み書きできるので、推測されにくいもの（「ランダムな合言葉を作る」推奨）にしてください。
・オフライン中に押したスタンプは、次に接続したときに反映されます。

■ ポケふたデータ
・data/pokefuta.js（アプリが読み込む）と data/pokefuta.csv（確認・編集用）に496枚分を収録しています。
・出典：ポケモンローカルActs公式サイト https://local.pokemon.jp/manhole/ の掲載内容（2026年11月11日取得）。番号は公式サイトの紹介ページの番号（/manhole/desc/番号/）です。
・「設置予定」のもの（2026年11月下旬など）も含みます。詳細画面のメモ欄で確認できます。
・新しいポケふたが増えたら data/pokefuta.js を差し替えてください（index.html と sw.js の「pokefuta.js?v=1」の数字も上げると、ホーム画面のアプリにも確実に反映されます）。
・ポケふたのスタンプは店舗とは別の場所（meguri-visited-pokefuta）に保存されるため、店舗データを読み直しても消えません。
・端末間の同期（下記）は店舗とポケふたの両方が対象です。元の店舗版と同じ Firebase・同じ合言葉を使うと、店舗のスタンプは元の版とも共有されます。
・非公式のファンメイドアプリです。ポケモンの画像やロゴは使っていません（名前と公式ページへのリンクのみ）。

■ ファイル構成
index.html          アプリ本体
data/pokefuta.*     ポケふたの設置一覧（js：アプリ用、csv：確認用）
osm.js              店舗データ取得（OpenStreetMap）・ファイル読込
transit.js          電車・バス表示の路線図
layers.js           カーシェア・シェアサイクルの重ね合わせレイヤー
sync.js             端末間のスタンプ同期
sync-config.js      同期サーバー（Firebase）の設定 ← ここを編集
data/rail-lo.json   全国の鉄道路線の概略（縮小表示用）
data/rail/          1度区画ごとの路線・駅の詳細（表示範囲の区画だけ読み込み）
data/rail-lines.json, rail-meta.json  路線一覧／経路検索用の駅データ（国土数値情報 N02-19 を加工）
manifest.webmanifest, sw.js, icons/   ホーム画面追加・オフライン起動用
